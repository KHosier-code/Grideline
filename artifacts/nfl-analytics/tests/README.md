# Theme and keyboard browser checks

Run the web and API workflows first, then `pnpm test:theme`. This runs the signed-out desktop/mobile checks against the routed preview (`http://localhost:80` by default). Set `GRIDLINE_TEST_BASE_URL` if the routed app is elsewhere. Chromium is used from the Replit toolchain when available, otherwise from the standard Playwright installation.

To check Admin, supply `GRIDLINE_ADMIN_STORAGE_STATE=/absolute/path/to/authorized-clerk-state.json pnpm test:theme:admin`. Capture the state with Playwright's `context.storageState({ path: ... })` from a **real, already-authorized development Admin session** for the same origin; the file contains live session credentials. Do not commit it, share it, or use a production account. The Admin command fails if no state is provided or if the session is not authorized. It does not set claims, alter `ADMIN_USER_IDS`, or mock authorization responses. Refresh expired state from an authorized session when needed.

Run `pnpm --filter @workspace/nfl-analytics run test:teams-browser` with the web workflow running to check Team Evidence cutoffs and out-of-order responses in Chromium. The test mounts the real page on a test-only entry and intercepts only the team analytics API; it needs no live account or API worker.
