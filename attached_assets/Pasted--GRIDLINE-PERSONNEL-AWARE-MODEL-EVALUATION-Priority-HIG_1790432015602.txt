# GRIDLINE — PERSONNEL-AWARE MODEL EVALUATION

**Priority: HIGH**

**Objective:** Execute the existing Task #68 evaluation framework to determine whether personnel-aware models improve upon Gridline's Phase 6.1 baseline.

This is an evaluation task, not a model development or production deployment task.

Do not build another evaluation framework if the existing one works.

## PHASE 1 — RECOVER EXISTING WORK

Locate and inspect:

- Task #68's personnel-aware comparison runner.
- The retained Phase 6.1 evaluation framework.
- The immutable 2025 recorded-market baseline.
- Existing personnel feature definitions.
- Historical feature and prediction-cutoff safeguards.

Determine whether the existing comparison can execute against the current development database.

Do not retrain production models, change algorithms or modify production data.

If a required dependency is missing, identify and repair only that dependency.

## PHASE 2 — EXECUTE THE COMPARISON

Evaluate three independent model families:

1. Spread.
2. Moneyline.
3. Totals.

Train the evaluation-only challengers using 2021–2024 data.

Evaluate on the same eligible 2025 games used by the existing baseline, with identical eligibility rules and grading.

Reconstruct personnel information using only evidence available before each game's historical prediction cutoff.

Enforce chronological integrity and prevent future-data leakage.

Keep the original Phase 6.1 baseline evidence immutable.

Verify that the baseline and challenger use identical eligible game IDs within each market family.

If the existing framework cannot reproduce the retained baseline, stop and report why.

## PHASE 3 — MEASURE ACTUAL PERFORMANCE

Produce the following comparisons.

### Spread

- Baseline MAE and RMSE.
- Challenger MAE and RMSE.
- Recorded-market MAE and RMSE.
- Baseline ATS results.
- Challenger ATS results.

### Moneyline

- Eligible game count.
- Baseline accuracy.
- Challenger accuracy.
- Recorded-market benchmark.
- Log loss.
- Brier score.
- Probability calibration.
- Price-aware returns where available.

### Totals

- Eligible game count.
- Baseline MAE and RMSE.
- Challenger MAE and RMSE.
- Recorded-market MAE and RMSE.
- Baseline over/under results.
- Challenger over/under results.
- Performance by model-versus-market difference.
- Price-aware returns where supported.

Use recorded-market terminology unless the source actually proves that a historical observation was a closing line.

Do not invent missing sportsbook prices or apply assumed odds.

## PHASE 4 — PERSONNEL FEATURE ANALYSIS

Determine which personnel features are genuinely contributing information.

Evaluate the availability and historical validity of:

- Starting QB certainty.
- QB continuity.
- Injury availability.
- Offensive-line continuity.
- Skill-position availability.
- Defensive personnel.
- Secondary availability.
- Depth-chart information.

Identify features that are missing, sparsely populated or reconstructed from potentially unreliable historical evidence.

If the existing framework supports legitimate feature ablation, report the results. Otherwise, document feature coverage without claiming causal contributions.

Do not fabricate historical injury or starter information.

## PHASE 5 — STATISTICAL RELIABILITY

Calculate paired game-level differences.

Include reasonable uncertainty estimates for key metrics.

Identify whether observed improvements are consistent across:

- Regular-season weeks.
- Different market conditions.
- Different model-difference ranges.
- High- and low-sample situations.

Avoid claiming that a small historical improvement establishes a profitable betting strategy.

Do not optimize thresholds, change weights or select a model based on repeatedly testing the same 2025 season.
