--------------------------------------------------
1. REMOVE MISLEADING CONFIDENCE
--------------------------------------------------

Current Games UI can display constructs such as:

"Key Recommendation"
"Confidence 100%"

Do not show 100% prediction confidence unless a validated system truly produces that probability.

Data completeness is NOT prediction probability.

Until validated confidence scoring exists:

replace:

KEY RECOMMENDATION

with:

GRIDLINE MODEL VIEW

or:

MODEL LEAN

Replace ambiguous "Confidence 100%" with appropriate explicit concepts such as:

Model input quality
Data quality
Market freshness

Do not imply probability of wager success.

--------------------------------------------------

If it represents model output, rename it accurately.
