The goal is to prove that production predictions are generated from real, game-specific, cutoff-safe inputs.

15. Sample quality
16. Input-quality status

CRITICAL RULE

Missing feature values must NEVER be silently converted to zero unless zero is a legitimate, observed value for that feature.

If any required feature is unavailable:

- do not generate a production prediction
- do not persist a prediction snapshot
- mark the game as “Prediction pending — incomplete model inputs”
- expose the missing inputs in Admin/Data Health
- do not expose technical details to consumer users
