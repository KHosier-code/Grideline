GRIDLINE PHASE 6.1 — ARTIFACT-BACKED PRODUCTION MODEL RECOVERY

The live-model input audit confirmed that the currently promoted legacy Phase 6 models do not have immutable fitted artifacts and therefore cannot satisfy the new production-integrity requirements.

The goal of this task is to create reproducible, artifact-backed production candidates that match the approved Phase 6 configurations as closely as possible.

Do not add new model families.
Do not change feature definitions.
Do not use 2026 games for fitting.
Do not add Phase 7/v4 features to the model yet.
Do not promote automatically.
Do not fabricate historical equivalence.

CURRENT APPROVED CONFIGURATIONS

Spread:
- regularized linear regression
- include low-sample games
- feature version: pregame-v3
- training seasons: 2021–2025

Moneyline:
- logistic regression
- include low-sample games
- feature version: pregame-v3
- training seasons: 2021–2025

Totals:
- gradient boosting
- exclude low-sample games
- feature version: pregame-v3
- training seasons: 2021–2025

TASK 1 — TRAIN NEW REPRODUCIBLE CANDIDATES

Train one new candidate for each family using exactly the approved configuration.

Persist immutable fitted artifacts containing the exact learned model state required for inference.

Examples as appropriate:
- coefficients
- intercepts
- feature order
- scaling/normalization parameters
- tree structures
- estimator configuration
- random seed
- library/runtime version
- training-data cutoff
- feature version
- training seasons
- sample policy

The fitted artifact must be sufficient to reproduce inference without refitting.

TASK 2 — ARTIFACT IDENTITY

For every fitted artifact persist:

- artifact ID
- cryptographic checksum/hash
- model family
- algorithm
- feature schema
- exact feature order
- training seasons
- training cutoff
- sample policy
- hyperparameters
- random seed where applicable
- runtime/library versions
- training sample count
- creation timestamp

Artifacts must be immutable.

TASK 3 — VALIDATION

Run the existing prediction-safety and chronology/leakage checks.

Also verify:

- artifact can be loaded independently
- inference is deterministic
- feature count exactly matches expected schema
- feature ordering is fixed
- missing features fail closed
- non-finite values fail closed
- artifact checksum verifies before inference

TASK 5 — CURRENT GAME INPUT READINESS

After artifact-backed candidates exist, verify for upcoming games:

- pregame-v3 row exists
- exact required feature set exists
- all required values are finite
- provenance is valid
- cutoff is pre-kickoff
- QB context is explicitly available or unavailable with reason
- model vector reconstruction succeeds

Do not generate a prediction where inputs are incomplete.

TASK 6 — SHADOW PREDICTIONS

Generate shadow predictions only.

Do not make them consumer-visible yet.

For at least 6 upcoming games report:

- matchup
- artifact ID
- populated feature count
- missing feature count
- QB confidence
- projected margin
- projected total
- home win probability
- input-quality status

Confirm input vectors differ across games.

TASK 7 — PROMOTION GATE

Do not promote automatically.

A candidate is eligible for manual promotion only if:

- immutable artifact exists
- artifact checksum verifies
- feature schema matches exactly
- chronology/leakage tests pass
- safety tests pass
- current-game inference succeeds on complete inputs
- historical evaluation is acceptably consistent with prior Phase 6 performance

Mark legacy models clearly as:
