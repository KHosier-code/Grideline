TASK — 2025 PHASE 6.1 CLOSING-LINE BACKTEST BASELINE

Goal:
Create a legitimate 2025 market-comparison baseline for the current Phase 6.1 Gridline models using historical closing spreads and closing totals.

This is an evaluation task only.

Do NOT:
- change live Phase 6.1 models
- retrain production models
- promote any model
- rewrite historical production predictions
- fabricate historical sportsbook data
- use future information
- use current 2026 injury/depth data in 2025 evaluation

The purpose is to answer:

“How would the current approved Phase 6.1 modeling approach have performed against 2025 closing NFL spreads and totals using strict walk-forward, pregame-only information?”

--------------------------------------------------
1. HISTORICAL MARKET DATA DISCOVERY

Find a legitimate source for 2025 NFL historical market lines.

Priority:

1. Verified closing spread and closing total from a source that explicitly identifies the values as closing lines
2. If only recorded historical market lines are available, preserve that terminology and do NOT call them closing lines
3. If multiple books are available, preserve book/source identity

Prefer a reproducible data source that can be imported and retained for audit.

For each game capture where available:

- game ID / matchup
- kickoff
- market source
- sportsbook if known
- closing home spread
- closing away spread/orientation
- closing total
- closing prices if available
- opening spread if available
- opening total if available
- market timestamp if available
- source provenance

Do not silently infer spread orientation.

Match 2025 historical market rows to Gridline NFL games.

- duplicate market rows

Generate legitimate 2025 walk-forward predictions.

Use the approved Phase 6.1 modeling configurations:

Spread:

- approved low-sample policy

- pregame-v3 schema
- approved low-sample policy

Totals:

At minimum preserve the earlier Phase 4 walk-forward structure:
- training through 2024 for 2025 evaluation

If finer week-by-week expanding-window 2025 retraining is statistically and architecturally supported, report it separately rather than mixing methodologies.

Do not use 2026 data anywhere.
