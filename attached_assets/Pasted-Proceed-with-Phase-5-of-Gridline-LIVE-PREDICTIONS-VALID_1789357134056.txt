Proceed with Phase 5 of Gridline: LIVE PREDICTIONS, VALIDATION, AND CONTROLLED CONTINUOUS LEARNING.

Do not automatically promote any model.

The objective is to begin generating real forward-looking NFL predictions, freeze them historically, grade them after games, compare them to sportsbook markets, and retrain challenger models as new games are completed.

Use only explicitly reviewed/promoted models for official predictions.

---

---

Add administrator-controlled promotion.

Model Lab should allow an admin to promote one reviewed candidate for each market:

* Spread
* Moneyline
* Totals

Promotion must be explicit.

Store:

* model version
* algorithm
* feature version
* training data cutoff
* promotion timestamp
* promoted by
* reason/notes

Never overwrite previous production-model history.

Allow:

Production
Challenger A
Challenger B

Include low-sample observations

Totals:
Gradient boosting

Do not automatically promote them.

2. WEEKLY PREDICTION GENERATION

---

Once a production model is explicitly promoted, generate predictions for upcoming NFL games.

For every model run store:

* game_id
* prediction timestamp
* feature-set version
* model version
* training cutoff
* projected home score where derivable
* projected away score where derivable
* projected margin
* projected total
* home win probability
* away win probability

If sportsbook data exists at prediction time, also store:

* DraftKings line
* DraftKings price
* FanDuel line
* FanDuel price
* best available line
* best available price
* market implied probability
* no-vig implied probability where possible
* model-vs-market edge

Every prediction must be immutable.

Never rewrite an earlier prediction simply because the model reruns later.

5. PREDICTION GRADING

---

After games finish, automatically grade official final predictions.

Spread:

Track model projected margin error.

If a legitimate sportsbook spread was captured pre-kickoff:

* win
* loss
* push

Moneyline:

* prediction accuracy
* Brier score
* log loss

Totals:

* projected total error

If legitimate sportsbook total was captured:

* Over win/loss/push
* Under win/loss/push

Never fabricate a market result when no line was captured.

10. CHALLENGER EVALUATION

---

Compare every new challenger to production using:

* historical walk-forward performance
* current-season forward performance
* MAE/RMSE
* Brier score
* log loss
* calibration
* stability
* sample size
* sportsbook edge performance when available
* CLV when available

Do not automatically promote a challenger simply because one metric is slightly better.

Flag:

Potential upgrade

only when improvement is meaningful and stable.

Require administrator approval for promotion.

11. RECENCY LEARNING

---

Create configurable candidate weighting strategies.

Test examples such as:

A. Full historical expanding window
B. Recent seasons weighted more heavily
C. Current season + prior season emphasized
D. Rolling multi-season window

Do not hardcode arbitrary weights as production truth.

Evaluate these weighting strategies as challenger variants.

Examples may include exponential sample weighting, but must be validated chronologically.

* totals residual changes
* QB-change error spikes
* edge buckets no longer performing as expected

Display:

Stable
Monitor
