TASK C — DEPTH CHART + STARTER INTERPRETATION

Goal:
Use Sleeper plus existing Gridline sources to build a current, evidence-backed NFL depth-chart/personnel layer.

Scope ownership:
- depth interpretation
- starter selection
- QB certainty
- conflict handling
- current team depth API
- matchup-ready personnel output
- no consumer UI
- no Phase 6.1 changes

Inputs:

Sleeper:
- current depth order
- team
- position
- status
- injury/practice context

nflverse:
- historical snaps
- participation
- QB game history
- prior depth evidence

ESPN:
- primary current injury/game status

HARD SAFETY RULES

Do not:
- change active Phase 6.1 schema
- retrain/refit/promote models
- rewrite predictions
- claim a published depth order is official NFL data
- fabricate WR-CB coverage assignments

SOURCE INTERPRETATION

Use:

1. permitted official source if one exists
2. Sleeper current published depth signal
3. nflverse participation/snaps
4. historical fallback/inference

ESPN remains primary for current injury designation.

Sleeper injury/practice fields are supplemental.

Special teams:

- player

- confidence
- reason

TASK 2 — QB STARTER CERTAINTY

Improve personnel-context QB certainty using:

- Sleeper QB depth order
- nflverse recent QB snaps/dropbacks

- role continuity
- conflicting evidence

Do not change Phase 6.1's trained feature definition unless it already consumes this personnel signal through an approved path.

Every QB certainty result must include:

- selected QB
- confidence
- evidence
- unavailable/conflict reason

Never silently default to 0.

- depth order missing

Return:

- selected interpretation
- confidence reduction
- reason
